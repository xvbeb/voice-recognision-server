Покажите панель закладок Chrome (⌘⇧B на Mac / Ctrl+Shift+B). Перетащите одну кнопку на панель. Затем откройте Gemspace и нажмите созданную закладку.

Автономная — основной вариант

🎤 q — автономная

Весь скрипт внутри закладки, без загрузки JS. После изменения test.txt закладку нужно установить заново. После обновления страницы Gemspace нажмите её снова.

Автообновление — загрузчик с нашего сервера

🎤 q — автообновление

При каждом запуске загружает текущую версию q-runtime.js по адресу https://voice-recognision-server-production.up.railway.app/q-runtime.js при условии, что CSP Gemspace и политики Chrome разрешают загрузку. Если загрузка не удалась, используйте автономную закладку.

После запуска, если кнопок нет, перейдите в другой чат и обратно: исходный скрипт перехватывает только новые ответы API. Поддерживаются VoiceMessage и CircleVideo; интерфейс исходного скрипта сохранён.

CSP может запретить JS, стили, HTML или запросы к медиа/Railway даже автономному варианту. Если сама javascript:-закладка заблокирована, она не сможет показать сообщение об ошибке. Не отключайте защиту браузера.
